# Настройка Яндекс.Метрики для BIGAS VIRUS

## Что уже сделано:

✅ Установлен счётчик Яндекс.Метрики на сайт  
✅ Автоматическое отслеживание переходов между разделами  
✅ Отслеживание важных событий (цели)  
✅ Вебвизор для анализа поведения пользователей  

## Как создать свой счётчик:

### 1. Зайдите в Яндекс.Метрику
Перейдите на [metrika.yandex.ru](https://metrika.yandex.ru) и войдите в аккаунт

### 2. Создайте счётчик
- Нажмите "Добавить счётчик"
- Укажите адрес сайта
- Включите опции:
  - ✅ Вебвизор
  - ✅ Карта кликов
  - ✅ Электронная коммерция (для e-commerce)

### 3. Получите номер счётчика
После создания вы получите **номер счётчика** (например, 12345678)

### 4. Замените номер в коде
Откройте файл `index.html` и найдите строку:
```javascript
ym(98765432, "init", {
```

Замените `98765432` на ваш номер счётчика.

Также замените в файле `src/components/YandexMetrika.tsx`:
```typescript
const METRIKA_ID = 98765432; // <- замените на ваш ID
```

## Отслеживаемые события (цели):

Настройте следующие цели в Яндекс.Метрике:

| Название цели | JavaScript событие | Описание |
|--------------|-------------------|----------|
| `section_view` | `section_view` | Просмотр раздела сайта |
| `vk_group_open` | `vk_group_open` | Открытие группы VK |
| `vk_subscribe_click` | `vk_subscribe_click` | Клик на подписку VK |
| `photo_upload` | `photo_upload` | Загрузка фото игрока |

### Как добавить цель:
1. В Яндекс.Метрике перейдите в **Настройки → Цели**
2. Нажмите **Добавить цель**
3. Выберите тип **JavaScript-событие**
4. Укажите идентификатор из таблицы выше
